# Eikon Academy Portals

- Student site: your-address.vercel.app/  (index.html)
- Staff site:   your-address.vercel.app/staff  (staff.html)

Both use the same app.js and styles.css. The server files (rpc.js, _lib.js, _seed.js) must sit inside a folder named api.

Settings to add in Vercel are listed in env-settings.txt.
